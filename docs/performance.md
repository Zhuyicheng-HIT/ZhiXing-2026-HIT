## 不改变视觉范围的优化

默认整个云台扫视矩形仍为80m边长，仍是待标定的仿真假设；没有扩大相机覆盖，也没有缩短每个合成观察点的2秒观察时间。默认飞机站位由152减少到142，合成观察点由1368减少到1278。

规划器只删除其余矩形已能覆盖的冗余站位，先按可飞区域的连通片分组，再用区域内实际最短路径进行近邻排序与局部路径改进。一个连通片只访问一次，房区跨片升高转场由3次减为1次。实际飞行仍受原来的区域、隔离带及树林条件授权约束。没有把不可达边界或禁飞区静默删除。

`validate_station_routes.py` 核验40/80/120m配置的站位归属、每片仅访问一次、跨片次数、删除站位后覆盖不退化及连续理想轨迹分离。默认80m全场平面矩形并集覆盖100%。这不是各机独立覆盖100%，也不包含图像清晰度、遮挡或YOLO识别证据；个别机的局部缺口及40m配置的全场小缺口保留在报告中。

## 完成后排队，不再等全组搜索结束

六机完成入场后，完成搜索的飞机登记FIFO返场队列。协调器在共享过境通道空闲时批准队首返场；通道占有一直持续到该机实际落地并解除锁定。其他飞机继续在各自区域工作，下一返场机在原扫描站位等待，不自己切换RTL。

入场、跨片升高转场、返场仍共用独占令牌。飞机完成搜索不是立即独立返航，后端不会绕过其他飞机已占有的通道。故障仍锁存实际位置，保留扫描游标、命令ID及队列断点。暂停不能使已经处于LAND模式的飞机瞬时悬停。

运动学预演按搜索结束顺序安排返场，并让当前规划的高层转场完成后再开始返场。原生SITL按实际完成事件及通道令牌调度，两者不具有完全相同的时间轴，不能用名义进度代替实际比赛耗时。

## 耗时证据

**当前可执行名义指向门控版**：`validation/sitl_feasible_pointing_report.json` 完成142站、1278次合成观察、六机落地与故障恢复，实际2599.501秒（43.33分钟）。1278次均通过实际机体姿态下名义候选视线误差门控，最大计算误差0.10024°；精确yaw仍有51次超限诊断，不被抹掉。它们不等价于真实云台反馈或标定后的机械可达性。该报告取代以下仅航向门控版作为当前科一耗时；7.498秒差异是不同运行采样结果，不视为已证明的性能提升。

**当前航向闭环版本**：`validation/sitl_heading_aligned_report.json` 完成142站、1278次合成观察、六机落地及断点恢复，实际2606.999秒（43.45分钟）。每点增加 `SCAN_ALIGN`，观察计时不计入航向刚到位的稳定确认周期。该时间取代下述未加入显式航向等待版本作为当前科一耗时；不能为了通过比赛时限删掉真实到位等待。精确实际姿态指向仍有43次名义超限，合成观察完成不能当作真实云台扫描验收。

仅路径及去冗余优化的完整原生SITL报告是 `validation/sitl_route_optimized_report.json`：142站位、1278次合成观察、六机全部落地，故障恢复通过，实际2715.2秒（45.25分钟）。与统一坐标基线2884.601秒相比节省169.401秒，仍超出科一25分钟和科二30分钟。对比数据在 `validation/station_route_comparison.json`。

协调提前返场的独立复验报告为 `validation/sitl_coordinated_return_report.json`，只能以该报告的完整运行结果判定；路径优化报告不能证明提前返场已经通过。

该独立复验已完整通过：六机正常解锁、1278次合成观察、故障恢复、全部落地解除锁定；飞控实际2068.0秒（34.47分钟），比统一坐标基线节省816.601秒（约28.3%），仍超过科一及科二时限。采样最小三维距离16.912m，43656次位置审计未出现周界或工作约束区越界；最低区外模拟高度39.964m，不能声明严格不低于40m。没有实机或连续物理无碰撞证明。

原生执行器额外输出 `phase_elapsed_s`，从2m悬停确认后按各机FCU时间累计状态耗时。网页分别显示飞行、观察、排队分钟数；暂停/故障保持及已落地COMPLETE等待另列在原始报告中，不混入这三项。相邻反馈时刻之间的时间按当时状态分类，统计有采样边界误差；不包括最初解锁/起飞，不能取代 `fcu_mission_elapsed_s` 的整场计时。

## 复验

```bash
python3 scripts/validate_station_routes.py
python3 scripts/validate_waypoint_executor.py
python3 scripts/validate_simulation.py
python3 scripts/verify_sitl.py --timeout 900 --authorize-forest-transit --report validation/sitl_coordinated_return_report.json
```

最后一个命令会启动真实SITL飞行，只能对当前本项目服务使用。树林授权只用于条件仿真，不是主办方许可。真实云台扫描范围、目标处理时间、风场、实际地形及实机动力模型没有验证，不能将本次优化当成比赛达标。
