# 飞行边界、工作高度与运行时保护

当前已增加全高度隔离带检查和起飞前拒绝。旧路线存在5段进出场穿带，旧完整报告仅证明工作阶段分区约束，不能证明全高度禁飞。显式隔离穿越仅供非合规条件演示；待确认的端部通道候选见 `isolation_airspace.md`。本页历史“隔离带仅工作阶段”等描述不再代表默认授权。

## 当前执行定义

- `config/flight_safety.json` 是当前任务规划与原生SITL的安全几何配置；不是飞控参数文件，也不是实机授权。六机共同使用地图ENU坐标系，起降位置可读回并重新生成航线。
- 用户确定的名义侦察高度仍为40m。指令增加0.5m控制余量，实际导航和扫描目标为40.5m。科一规则高度40–120m、科二30–120m；本方案科二也保持40m运行下限。起降区内的同时起飞、2m等待和垂直回收是单独阶段。
- `flight_region` 为本机真正作业分区，扣除中间隔离带，不再外扩4m后声称未越界。`navigation_region` 是该区域向内缩4m后的规划域；航点放在内部，不等于允许跨越边界4m。
- 六机作业分区之间保留20m隔离带。工作、扫描、工作区内爬升和等待返场阶段不允许进入另一架的区域或隔离带。高层进出场仍使用统一周界内的排他通道，不受单机工作分区约束；因此当前不是“隔离带所有高度均禁飞”的方案。若要求全高度禁飞，需要重新确认通道拓扑，不能直接把现有路线称为合规。
- 周界内缩2m用于进出场路线规划；0.6m水平机体半径用于执行器的额外几何检查。这只是700mm机架和18寸桨的名义估计，未测量实际桨尖包络，不含风、定位误差、制动距离、建筑物高度和垂直机体包络。

## 执行器如何保护

`scripts/flight_safety.py` 在原生执行器下发下一位置指令前，检查反馈位置与目标之间的直线是否位于允许区域，是否穿过未经授权的树林，以及高度上下限。另将机体中心允许区域内缩估计半径，检查名义水平包络；不是只检测航点末端。

一次拒绝就保留所有任务游标、观察命令和尝试，记录 `FLIGHT_BOUNDARY_HOLD`，六机保持各自反馈位置，不自动跳点、改变禁区或独立RTL。网页显示原因；确认位置、目标和许可后，可点击“核对并解除边界保持”。若条件仍不满足，下一次检查会重新保持。

这是拒绝不安全任务指令的保护，不是避障器。已经越界时保持当前位置不能消除已发生的越界；离散反馈检查不能证明两次反馈之间的完整物理轨迹安全。暂停、异常和人工恢复后的处置仍需协调，不能据此承诺任何情况下零碰撞。

## 许可及实机边界

当前树林全高度禁止会切断东西侧通路，完整运行需明确勾选条件仿真树林通行。这个开关不是主办方批准，也不是取消科目三区域限制。只有实际规则允许的通道或修订起降/路线方案，才可向实机迁移。

当前高度以平地仿真参考面计算，71m基准海拔也是场景假设；没有测绘地形或建筑DSM，不能把模拟AGL直接当作整个赛场真实离地高度。实机还需校准RTK坐标、云台安装、光学覆盖、机体包络和避障/制动余量，并落实共同失联处理。规划器与状态机可以复用，许可和物理安全不能由复用自动获得。

## 复验

```bash
python3 scripts/validate_flight_safety.py
python3 scripts/validate_waypoint_executor.py
python3 scripts/sitl_server.py --speedup 20
```

另一终端执行完整科一条件仿真：

```bash
python3 scripts/verify_sitl.py --authorize-forest-transit --timeout 900 --report validation/sitl_exact_boundary_report.json
```

科二搜索前段另启动 `python3 scripts/sitl_server.py --speedup 20 --mission-config config/sitl_subject2.json`，使用不同报告名；不要同时启动占用相同端口的两个服务。网页正常演示建议使用5倍速，不要把20倍速墙钟测试等同于比赛耗时。

报告的 `sampled_exact_boundary_and_altitude_passed` 只表示所采样中心位置和检查的直线目标合规；`sampled_estimated_horizontal_envelope_passed` 只针对0.6m名义水平半径。它们不证明连续碰撞安全、实测包络安全、真实视觉覆盖或科二投放完成。
# 当前用户确认口径（2026-10-06）

科目一、科目二的合法空域是25个周界点围成的整块区域。树林只是不搜索，允许作为进出场过境空域；进出场不得越过周界。六架飞机的水平作业区不重叠，工作区之间保留20m间隔；隔离带穿越只保留为历史诊断，不作为当前启动拒绝条件。动态目标离开本机作业区后直接放弃，不交接、不越区跟随。当前配置见 `config/airspace_policy.json`。
